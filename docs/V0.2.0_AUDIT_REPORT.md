# YookAI v0.2.0 — Implementation & Regression Report

## Scope

All eight v0.1.0 follow-up ideas were implemented, followed by syntax checks and the full Python test suite.

## 1. Document intelligence

Attachments now extract local text from TXT/Markdown/CSV/JSON/XML/HTML/CSS/JS/Python/log/YAML/SQL plus PDF, DOCX, XLSX and XLSM. Extraction is stored in attachment metadata and reused when building provider context.

## 2. Memory manager

The memory store now has a deterministic local vector representation (hashing over tokens and token bigrams) and cosine retrieval. This keeps retrieval fully local without a hosted embedding service. The UI supports search, delete and clear. Default memory remains global to the local installation; Project-only remains isolated by project id.

## 3. Usage accounting

Provider usage events are persisted on assistant messages. Statistics expose estimated tokens, actual prompt/completion tokens, total tokens, duration and an estimated USD cost when a pricing snapshot is available.

## 4. Session export/import and search

Sessions can be exported as JSON and imported into a new local session. Chat search is available from the sidebar and Ctrl+/. 

## 5. Attachment lifecycle

Attachments can be listed/deleted through API routes and orphan files can be cleaned by scanning all persisted sessions.

## 6. Provider capability layer

OpenRouter model metadata now includes context length and normalized vision/reasoning/tool capability hints, allowing later UI/model budgeting work without changing the provider contract.

## 7. Frontend E2E groundwork

The frontend was refactored into stable semantic components and all existing static/frontend regression checks remain green. Drag/drop upload, modal flows, keyboard shortcuts, responsive sidebar behavior and composer states were checked through source-level regression tests. A real browser runner is still a v0.3.x candidate.

## 8. Provider abstraction / context budgeting groundwork

The provider interface remains isolated from application routes, while model capability metadata and attachment extraction make future automatic context budgeting possible without another frontend rewrite.

## Visual refactor

The v0.2.0 visual system is intentionally ChatGPT-inspired: compact neutral sidebar, centered model selector, minimal header, large unconstrained assistant responses, rounded user bubbles, floating bottom composer, subtle borders, familiar modal patterns, dark/light theme parity, and mobile drawer behavior. YookAI-specific branding and localhost controls remain distinct.
