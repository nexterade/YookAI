# YookAI v0.3.0-rc1

## RC1 scope

RC1 focuses on frontend interaction quality and streaming performance while preserving the beta2 provider/router/tool architecture.

### UI refactor
- ChatGPT-inspired compact hierarchy and composer.
- Responsive sidebar transitions.
- Reduced visual chrome and consistent interaction states.
- Modal/dropdown entrance transitions.
- Reduced-motion support.

### SVG icon system
Runtime attachment and primary message actions use the shared inline SVG registry. Unicode pictograms are not used for attachment chips.

### Loading and streaming UX
- Send button displays a spinner while generation is active.
- Streaming assistant messages use a subtle cursor.
- Thinking indicator stops and becomes finalized on content/done/stop.
- Upload progress retains an active spinner until the server confirms completion.

### Streaming performance
Markdown rendering is coalesced with `requestAnimationFrame` rather than rendering on every provider chunk. A final synchronous render is performed when the stream completes.

### Compatibility
The existing beta2 API/provider/tool/session architecture remains intact.

## Testing

RC1 adds static regression tests for the UI/streaming changes. Full integration tests may require a writable `~/.yookai` runtime in the host environment.
