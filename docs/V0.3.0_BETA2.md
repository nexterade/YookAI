# YookAI v0.3.0-final

## Local AI Tools

Beta2 introduces a local tool subsystem designed around explicit permission boundaries.

### Built-in tools

- `calculator` — safe AST-based arithmetic; no Python execution.
- `filesystem.list` — list files inside `~/.yookai/workspace`.
- `filesystem.read` — read UTF-8 text inside the workspace with a size limit.
- `shell` — optional, disabled by default; when enabled it is restricted to an allowlist, runs without a shell interpreter, uses the workspace as cwd, and requires a one-time confirmation token.

### API

- `GET /api/tools`
- `POST /api/tools/execute`

A dangerous tool returns `status=confirmation_required` and a short-lived one-time token. The token must be submitted with the same tool name to execute the operation.

## Security model

The filesystem tools resolve paths against the canonical workspace and reject path traversal. Shell execution uses `subprocess.run(..., shell=False)` and rejects shell operators, absolute paths, and parent traversal. Shell is disabled unless explicitly enabled in configuration.

This beta does **not** yet allow providers to autonomously execute tools. The tool layer is intentionally established first so provider function/tool-calling can be integrated behind the same permission boundary in the next beta.
