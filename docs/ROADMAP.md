# Roadmap

## v0.2.0 — completed
All eight planned capability groups are implemented in the local build.

## v0.3.x candidates
- True local embedding models (optional sentence-transformer backend).
- Tool calling and MCP-style local integrations.
- Background indexing queue for large attachment collections.
- Import/export bundles with attachments and memory.
- Browser E2E regression suite.
- Multi-provider capability negotiation and model context budgeting.

# Roadmap

Planned scope, subject to change:

- **v0.2** — Attachments, system prompt, export/import.
- **v0.3** — Multi-provider support: OpenAI, Gemini, Anthropic.
- **v0.4** — Web search, citations, conversation branching.
- **v0.5** — Tools, agents, workspace.
- **v1.0** — PWA, multi-user support, cloud sync.

The Memory Layer begins after the v0.1 baseline and is intentionally outside this release.


## Completed in the audit/refactor
- Durable local memory modes and attachment upload/storage.
- Conversation statistics and provider usage capture.
- Sidebar collapse/close behavior and streaming/session race fixes.
- Expanded regression coverage and JavaScript syntax checks.
