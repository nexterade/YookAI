# YookAI v0.3.0-alpha2

Alpha2 turns the architecture foundation into a usable provider/model intelligence layer.

## New
- Provider Registry 2.0: metadata, base URLs, local vs remote classification.
- Live model catalog: normalized descriptors across registered providers.
- Capability inference: reasoning, vision, tools, streaming and JSON mode.
- Provider health checks without generating a chat completion.
- Latency benchmark orchestration; providers may expose a native safe benchmark.
- API: `GET /api/providers`, `GET /api/models`, `GET /api/providers/health`, `GET /api/providers/{name}/health`, `POST /api/providers/{name}/benchmark`.

## Safety/performance
Generic providers are not sent arbitrary benchmark prompts. A provider must expose a native benchmark method to perform TTFT measurement; otherwise Alpha2 falls back to model-list discovery only.
