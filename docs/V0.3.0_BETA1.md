# YookAI v0.3.0-beta1

## Smart routing

Beta1 introduces an explicit routing domain for automatic model/provider selection.

- `model: "auto"` (or an omitted model) enables automatic selection.
- Explicit `provider` + `model` remains authoritative.
- `chat.model_strategy` supports latency-oriented selection, including `latency-best-free`.
- Model capabilities can constrain routing through `options.required_capability` or `options.require_vision`.
- Cached benchmark results are preferred; the router does not issue billable probe calls.
- Provider/model fallback is attempted only before the first generated content/reasoning token.
- A short in-process model catalog cache reduces repeated provider discovery latency.

## Sessions

Session JSON now carries `schema_version: 2`, `model_config`, and `routing` fields while remaining backward compatible with existing sessions.

## Attachments

The existing bounded ZIP/document extraction pipeline is now part of the beta baseline. Archives are inspected in memory with file/member/expanded-size limits; files are never extracted into arbitrary filesystem paths.

## API behavior

`POST /api/chat` can automatically choose a model when `model` is omitted or set to `auto`.
Explicit model selection is never silently replaced.
