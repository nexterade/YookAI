1. Mengenal YookAI

Satu antarmuka lokal untuk menggunakan beberapa layanan AI dan model.

YookAI adalah workspace chat multi-model yang berjalan di perangkat sendiri melalui server Python lokal. Browser menjadi antarmukanya, sedangkan provider yang dipilih memproses permintaan AI. YookAI mendukung streaming jawaban, pemilihan model, sesi percakapan, memory, lampiran, serta beberapa tools lokal.

Proyek & pengembang

YookAI dikembangkan dan dipelihara oleh @nexterade. Buka repository untuk mendapatkan source code, membaca dokumentasi, melihat pembaruan, atau melaporkan masalah.

Lihat source code di GitHub ↗

Web UI

Antarmuka chat di browser untuk memilih provider/model, mengirim pesan, melihat hasil, dan mengatur sesi.

CLI

Menu terminal untuk konfigurasi awal, mengatur provider, menjalankan pemeriksaan, dan mengelola data.

Local-first

Server default hanya mendengarkan di 127.0.0.1. Data runtime disimpan lokal; prompt tetap dikirim ke provider saat chat cloud digunakan.

Provider pilihan

Gunakan provider gratis yang tersedia, model lokal melalui Ollama, atau endpoint OpenAI-compatible milik sendiri.

2. Persiapan

Siapkan perangkat dan akses provider sebelum instalasi.

  • Python 3.10 atau lebih baru.
  • Git untuk meng-clone source repository YookAI.
  • Koneksi internet untuk memasang dependency dan memakai provider cloud.
  • Browser modern untuk membuka Web UI.
  • API key dari provider pilihan, kecuali menggunakan Ollama lokal atau endpoint yang memang tidak memerlukan key.
  • Ruang penyimpanan untuk source, dependency, sesi, dan lampiran.
Android: YookAI dapat dijalankan melalui Termux, tetapi instalasi dependency Python tertentu mungkin berbeda antarperangkat. Gunakan Python dan paket Termux yang kompatibel. Jangan menganggap Ollama berjalan langsung di Android; biasanya perlu server Ollama terpisah yang dapat dijangkau lewat jaringan.

3. Instalasi YookAI

Clone source resmi dari GitHub, siapkan Python environment, lalu pasang dependency.

1. Pasang Git dan clone repository

Pastikan Git tersedia. Di Ubuntu/Debian atau Termux, kamu bisa memasangnya dengan:

# Ubuntu / Debian sudo apt update && sudo apt install -y git python3 python3-venv python3-pip # Android / Termux pkg update && pkg install -y git python

Di Windows, pasang Git for Windows terlebih dahulu jika perintah git belum dikenali. Lalu clone repository resmi:

git clone https://github.com/nexterade/YookAI.git cd YookAI

Pastikan terminal sekarang berada di root proyek, yaitu folder yang berisi server.py, requirements.txt, serta folder app/, core/, dan templates/.

2. Buka terminal di root proyek

Jika kamu belum berada di folder hasil clone, pindah ke folder YookAI. Di Android, gunakan Termux. Di desktop, gunakan Terminal atau PowerShell. Jalankan perintah instalasi dari root proyek agar file dependency ditemukan.

3. Buat environment dan pasang paket

Untuk Linux, macOS, atau Termux dengan dukungan Python venv:

python3 -m venv .venv . .venv/bin/activate python -m pip install --upgrade pip pip install -r requirements.txt

Di Windows PowerShell:

py -m venv .venv .venv\Scripts\Activate.ps1 python -m pip install --upgrade pip pip install -r requirements.txt

Jika PowerShell memblokir aktivasi script, gunakan sesi PowerShell yang diizinkan untuk menjalankan script atau jalankan interpreter environment secara langsung. Jika instalasi dependency gagal di Android, periksa pesan error dan kompatibilitas paket untuk perangkatmu.

4. Pastikan file konfigurasi tersedia

Pada start pertama, YookAI menyiapkan direktori runtime di ~/.yookai/ menggunakan contoh konfigurasi. Jangan mengedit file runtime atau menghapus folder data tanpa memahami dampaknya dan membuat backup terlebih dahulu.

4. Menjalankan server

Jalankan server lokal, lalu buka alamatnya di browser perangkat.

1. Jalankan YookAI

Dari root proyek dan environment yang sudah aktif, jalankan:

python server.py --no-open

CLI dapat menampilkan menu konfigurasi awal. Pilih provider, isi kredensial/Base URL, pilih model dan opsi lain sesuai kebutuhan, lalu pilih Save & start server. Opsi --no-open mencegah browser dibuka otomatis.

2. Buka Web UI

Di browser perangkat yang menjalankan server, buka:

http://127.0.0.1:8000/

Alamat ini adalah localhost—server hanya tersedia pada perangkat yang sama secara default. Jika halaman tidak terbuka, pastikan terminal menunjukkan server listening dan port 8000 tidak sedang dipakai proses lain.

3. Biarkan server tetap berjalan

Jangan tutup sesi terminal saat menggunakan Web UI. Untuk menghentikan server, kembali ke terminal dan tekan Ctrl+C. Saat ingin chat lagi, jalankan server kembali.

Android + Termux: jika browser dan Termux berada pada perangkat yang sama, gunakan 127.0.0.1:8000. Hindari membuka akses publik atau mengganti host ke jaringan luar kecuali kamu memahami autentikasi dan risiko keamanannya.

5. Mengenal antarmuka

Bagian utama yang akan sering digunakan dalam Web UI.

Sidebar / menu

Untuk mengakses percakapan, sesi tersimpan, pencarian, dan menu pendukung. Pada layar sempit, sidebar dapat dibuka dari tombol menu.

Provider dan model

Area header untuk melihat provider/model aktif dan menggantinya sesuai katalog yang tersedia.

Area percakapan

Menampilkan pesan user dan jawaban AI. Respons streaming muncul bertahap saat provider mengirim data.

Composer

Kotak input di bagian bawah untuk mengetik pesan, melampirkan file jika didukung, dan mengirim pesan.

Settings

Mengatur provider, API key, Base URL, model default, memory mode, dan project ID.

Model profile

Pengaturan per provider dan model seperti temperature, top-p, max tokens, reasoning effort, serta system prompt.

YookAI menyediakan tema gelap dan terang. Gunakan kontrol tema pada header jika ingin mengganti tampilan. Pada ponsel, gunakan tombol menu untuk membuka navigasi dan tutup kembali setelah memilih fitur.

6. Memilih provider AI

Pilih provider berdasarkan akses, model, privasi, dan batas akun.

Versi acuan panduan ini menampilkan provider free-first berikut. Provider cloud umumnya memerlukan akun dan API key. Paket gratis dapat memiliki kuota, pembatasan model, kelayakan akun, wilayah, atau rate limit yang ditentukan vendor.

1. Buka Settings

Buka menu Settings dari Web UI. Pilih provider yang ingin digunakan dari dropdown Provider. Provider yang dipilih menentukan kredensial, endpoint, dan katalog model.

2. Masukkan API key (untuk provider cloud)

Buat key dari dashboard resmi provider, lalu salin ke kolom API key. Jangan tempel key ke chat, screenshot, issue publik, atau source code. Ollama biasanya tidak memerlukan key secara default.

3. Periksa Base URL dan model

Gunakan Base URL default yang sesuai provider, kecuali vendor atau gateway yang digunakan memberi endpoint lain. Pilih Default model dari daftar yang tersedia. Simpan perubahan menggunakan tombol Save.

Perlu diingat: “free-first” berarti YookAI memprioritaskan provider yang menawarkan akses gratis, bukan menjamin setiap model gratis, selalu aktif, berkualitas sama, atau tanpa limit. Cek dashboard dan ketentuan provider sebelum mengandalkan layanan tertentu.

7. Mengatur Custom Provider

Gunakan akun atau endpoint OpenAI-compatible milik sendiri.

Custom Provider ditujukan untuk layanan yang menyediakan API kompatibel dengan OpenAI Chat Completions. Layanan itu bisa gratis, berbayar, self-hosted, atau gateway internal. Kompatibilitas tidak menjamin semua parameter dan fitur opsional berjalan sama.

1. Pilih Custom Provider

Buka Settings, lalu pilih Custom Provider pada pilihan Provider. Isi API key yang disediakan layanan, jika endpoint memerlukannya.

2. Masukkan Base URL

Masukkan URL dasar API sesuai dokumentasi layanan. Jangan menambahkan path Chat Completions pada akhir URL.

https://api.example.com/v1

Contoh di atas hanya placeholder. Ganti dengan URL resmi milik layananmu. Gunakan HTTPS untuk endpoint cloud, dan hindari URL yang memuat username, password, atau token.

3. Uji koneksi

Tekan Test connection bila tombol tersedia pada konfigurasi Custom Provider. YookAI mencoba menghubungi endpoint dan mengambil katalog model. Kegagalan bisa berasal dari key, Base URL, jaringan, kompatibilitas API, atau pembatasan layanan.

4. Pilih Model ID

Jika katalog model berhasil dimuat, pilih model yang tersedia. Bila katalog tidak disediakan atau tidak dapat dimuat, isi Model ID secara manual jika kolom manual tersedia. Pastikan ID sama persis dengan dokumentasi endpoint.

5. Simpan dan mulai chat

Tekan Save, pilih model aktif, lalu kirim pesan percobaan singkat. Mulailah dengan prompt sederhana agar lebih mudah membedakan masalah konfigurasi dari batas kemampuan model.

Keamanan: hubungkan hanya endpoint yang kamu percaya. API key memberikan akses ke akun layananmu dan dapat menimbulkan biaya. YookAI tidak dapat menjamin endpoint pihak ketiga aman atau sepenuhnya kompatibel.

8. Memulai percakapan

Pilih model, tulis instruksi yang jelas, dan evaluasi jawabannya.

1. Pilih provider dan model

Gunakan pemilih provider/model di bagian header. Ketika provider berubah, katalog model akan menyesuaikan provider tersebut. Pastikan model yang dipilih memang tersedia pada akun atau endpoint aktif.

2. Tulis pesan

Ketik pertanyaan atau instruksi pada kotak pesan di bagian bawah. Jelaskan konteks, tujuan, batasan, dan format hasil yang kamu inginkan. Hindari memasukkan password, API key, atau informasi sensitif yang tidak diperlukan.

3. Kirim dan tunggu respons

Tekan tombol kirim atau Enter. Respons streaming dapat muncul bertahap. Gunakan Shift+Enter untuk membuat baris baru. Jangan menekan Retry berulang kali tanpa memeriksa error, karena request tambahan dapat memakai kuota.

4. Kelola pesan

Tergantung kontrol yang tersedia pada pesan, kamu dapat menyalin teks, mengedit prompt user, atau mencoba ulang jawaban. Periksa hasil sebelum menggunakannya untuk keputusan penting.

Tips prompt: “Jelaskan [topik] untuk pemula dalam bahasa Indonesia. Berikan langkah bernomor, contoh praktis, dan sebutkan bagian yang belum pasti.” Prompt yang terarah biasanya lebih membantu, tetapi kualitas jawaban tetap bergantung pada model dan konteks.

9. Pengaturan model (Model Profile)

Atur perilaku model untuk pasangan provider dan model tertentu.

Buka menu pengaturan model sesi melalui kontrol yang tersedia di antarmuka. Profil disimpan per provider + model, lalu konfigurasi yang digunakan dapat disimpan sebagai snapshot pada sesi percakapan.

Temperature

Mengatur variasi keluaran. Nilai lebih rendah cenderung lebih konsisten; nilai lebih tinggi dapat menghasilkan variasi lebih besar. Rentang UI: 0–2.

Top P

Parameter sampling alternatif untuk membatasi kumpulan token. Rentang UI: 0–1. Sebaiknya ubah hanya bila memahami perilaku model.

Max tokens

Batas token keluaran yang diminta. Jangan melebihi batas model/provider. Context window bukan berarti batas output.

Reasoning effort

Opsi Auto, Low, Medium, High. Dukungan dan dampaknya bergantung pada adapter serta model yang dipilih.

System prompt

Instruksi tambahan untuk model/sesi, misalnya bahasa jawaban, peran, format, atau batasan tugas.

Save model profile

Simpan perubahan untuk profil provider/model. Perhatikan bahwa dukungan parameter opsional berbeda antarprovider.

Hindari mengubah banyak parameter sekaligus. Uji satu perubahan per percakapan agar kamu bisa menilai dampaknya. Provider dapat menolak parameter yang tidak didukung.

10. Sesi percakapan

Simpan, buka kembali, cari, dan ekspor percakapan.

YookAI menyimpan sesi secara lokal. Gunakan kontrol sesi pada sidebar untuk membuat chat baru, membuka percakapan tersimpan, dan melanjutkan diskusi sebelumnya. Sesi menyimpan informasi seperti provider/model, pesan, waktu, dan metadata.

  • New chat: mulai konteks percakapan baru agar topik tidak tercampur.
  • Restore session: buka sesi yang tersimpan dan lanjutkan percakapan.
  • Search chats: cari percakapan menggunakan kata kunci.
  • Statistics / Export: periksa statistik sesi dan ekspor JSON jika fitur tersedia.
  • Delete: hapus sesi hanya setelah yakin tidak lagi diperlukan.
File sesi berada pada direktori runtime ~/.yookai/sessions/. Backup folder runtime sebelum melakukan pembersihan, pemindahan perangkat, atau perubahan manual.

11. Memory lokal

Memory dapat membantu menjaga konteks lintas percakapan sesuai mode yang dipilih.

YookAI memiliki pengaturan memory dan antarmuka untuk meninjau memory yang tersimpan. Pilihan mode yang terlihat pada Settings mencakup Default memory dan Project-only memory. Project ID digunakan untuk mengelompokkan konteks proyek bila fitur tersebut dipakai.

  • Buka Settings dan pilih mode memory yang sesuai.
  • Atur Project ID jika ingin memisahkan konteks proyek.
  • Buka panel Memory untuk meninjau atau mencari item yang tersimpan.
  • Gunakan Clear current memory hanya jika memang ingin menghapus memory aktif.
Jangan menyimpan rahasia di memory. Tinjau isi memory secara berkala dan hapus informasi yang tidak lagi diperlukan. Memory lokal tidak berarti informasi yang disertakan dalam prompt tidak akan dikirim ke provider cloud.

12. Lampiran file

Sertakan file yang relevan saat meminta AI menganalisis dokumen.

Jika tombol lampiran tersedia pada composer, gunakan untuk memilih file yang didukung. Tunggu proses unggah/validasi selesai sebelum mengirim pesan. Jenis dan ukuran file yang diterima mengikuti validasi aplikasi yang terpasang.

  • Pilih file yang memang diperlukan untuk tugas.
  • Pastikan tidak ada password, token, atau data pribadi yang tidak perlu di dalam file.
  • Tulis instruksi spesifik, misalnya “Ringkas dokumen ini menjadi 5 poin” atau “Temukan bagian yang membahas konfigurasi”.
  • Periksa hasil ekstraksi dan jawaban AI; format kompleks, scan, atau gambar dapat membutuhkan pemeriksaan tambahan.
Lampiran yang dikirim ke model cloud dapat diteruskan ke layanan provider sesuai mekanisme adapter. Jangan unggah dokumen rahasia kecuali kamu telah memahami kebijakan dan persetujuan yang berlaku.

13. Tools lokal

Beberapa fungsi bantu dapat bekerja pada workspace lokal.

Panel Tools menyediakan utilitas seperti kalkulator dan operasi filesystem yang dibatasi pada workspace. Tool yang lebih berisiko, seperti shell opsional, nonaktif secara default dan memiliki pembatasan serta konfirmasi.

  • Gunakan kalkulator untuk operasi matematika sederhana.
  • Gunakan operasi filesystem hanya pada folder kerja yang dimaksud dan periksa path sebelum menjalankan aksi.
  • Jangan mengaktifkan shell kecuali memahami bahwa tool tersebut memberi kemampuan menjalankan perintah lokal sesuai pembatasannya.
  • Periksa hasil tool sebelum membagikan atau menggunakannya.
Tool bukan sandbox sistem operasi. Pembatasan aplikasi mengurangi risiko tetapi tidak menggantikan isolasi OS. Biarkan shell tetap nonaktif jika tidak benar-benar diperlukan.

14. Konfigurasi melalui CLI / Termux

Menu startup dapat digunakan untuk mengatur YookAI tanpa membuka Settings di browser.

Saat dijalankan dalam terminal interaktif, menu konfigurasi menampilkan pilihan seperti:

[1] Provider [2] Credentials / URL [3] Model [4] Memory [5] Server [6] Theme [7] Benchmark latency [8] Network test [9] .yookai Manager [10] Miscellaneous [S] Save & start server [Q] Quit

1. Provider

Pilih provider aktif dari daftar yang tersedia. CLI dapat menampilkan panduan singkat terkait credential dan endpoint provider tersebut.

2. Credentials / URL

Masukkan API key dan Base URL. Untuk Custom Provider, gunakan endpoint OpenAI-compatible tepercaya dan Model ID yang tersedia pada layanan.

3. Model dan opsi lainnya

Pilih model dan atur memory, host/port server, atau tema bila diperlukan. Benchmark latency menguji OpenRouter free models; Network test memeriksa Base URL provider dan bukan pengganti uji autentikasi API.

4. Simpan dan mulai

Pilih Save & start server untuk menyimpan konfigurasi dan menjalankan server. Pilih Quit untuk keluar dari menu. Hindari membagikan output terminal yang mungkin memuat informasi konfigurasi sensitif.

Untuk menjalankan server tanpa menu interaktif, gunakan python server.py --no-open. Menu startup dapat berubah mengikuti versi dan mode terminal.

15. Troubleshooting

Kenali penyebab yang mungkin dari pesan error dan lakukan pemeriksaan bertahap.

429 — Rate limit / batas penggunaan

Provider sedang membatasi request atau kuota sementara tercapai. Periksa dashboard provider, model yang dipilih, jendela reset limit, dan batas akun. Tunggu sebelum mencoba lagi atau gunakan model/provider lain yang memang tersedia. Retry tidak menambah kuota.

402 — Insufficient credits / billing

Periksa detail error dari provider. Status 402 dapat menunjukkan saldo/kredit atau entitlement yang tidak mencukupi, bukan selalu “model rusak”. Pastikan key berasal dari akun/organisasi yang benar, route/model mendukung akses akun, dan billing sesuai ketentuan vendor. Jangan menganggap semua model OpenRouter gratis.

401 / 403 — API key atau akses ditolak

Periksa apakah key benar, masih aktif, tidak terpotong spasi, berasal dari akun yang tepat, dan memiliki izin untuk model/API tersebut. Buat key baru jika key lama terekspos; jangan kirim key ke orang lain untuk diperiksa.

404 — Model atau endpoint tidak ditemukan

Pastikan Base URL benar dan tidak berisi path yang keliru. Periksa ejaan Model ID dan apakah model tersedia bagi akunmu. Untuk Custom Provider, ikuti format endpoint yang didokumentasikan oleh vendor.

500 / 502 / 503 — Gangguan provider

Layanan mungkin sedang bermasalah atau overload. Periksa status page provider jika tersedia, tunggu sebentar, lalu coba lagi. Jika berulang, uji provider/model lain untuk membedakan gangguan lokal dan gangguan vendor.

Model list gagal dimuat

Periksa koneksi, API key, Base URL, izin akun, dan log server. Beberapa endpoint tidak menyediakan katalog model yang kompatibel. Jika UI mendukungnya, masukkan Model ID secara manual yang benar-benar disediakan endpoint.

Browser tidak bisa membuka 127.0.0.1:8000

Pastikan server masih berjalan di terminal, port benar, dan browser dibuka pada perangkat yang sama. Jika port bentrok, periksa konfigurasi server. Jangan membuka server ke jaringan publik hanya untuk mengatasi masalah localhost.

Chat tidak menghasilkan jawaban

Periksa pesan error pada UI dan terminal. Pastikan provider/model aktif, credential tersimpan, kuota cukup, dan request diterima. Coba prompt singkat serta model lain. Hindari mengulang request berkali-kali tanpa memahami error.

Settings atau modal tidak bisa dibuka

Segarkan halaman setelah memastikan server berjalan. Jika masalah tetap terjadi, catat versi YookAI, browser/perangkat, langkah reproduksi, dan pesan error console/server. Samarkan API key, session ID sensitif, serta data pribadi sebelum mengirim laporan.

16. Privasi dan keamanan

YookAI local-first, tetapi pemakaian provider cloud tetap mengirim data keluar perangkat.

  • Gunakan localhost untuk Web UI pada perangkat sendiri.
  • Jangan commit atau membagikan API key, file settings, session, memory, dan lampiran.
  • Runtime data disimpan di ~/.yookai/; jaga izin akses folder tersebut.
  • Backup data penting sebelum membersihkan atau memindahkan runtime.
  • Gunakan endpoint HTTPS tepercaya untuk provider cloud.
  • Periksa isi prompt dan lampiran sebelum dikirim ke provider.
  • Jangan mengaktifkan shell opsional kecuali memahami risiko eksekusi lokal.
  • Jangan menganggap server bawaan sebagai gateway produksi multi-user yang sudah hardened.

YookAI menyamarkan kredensial pada respons konfigurasi API, tetapi pengguna tetap bertanggung jawab menjaga perangkat, backup, dan endpoint. Jika API key terlanjur terekspos, cabut atau rotasi melalui dashboard provider.

17. FAQ

Pertanyaan yang sering muncul saat pertama kali memakai YookAI.

Apakah YookAI sendiri gratis?

Source YookAI menggunakan lisensi MIT. Namun biaya layanan provider, penggunaan API, infrastruktur, dan resource perangkat mengikuti layanan yang kamu gunakan.

Apakah semua model gratis?

Tidak. Ada provider yang menyediakan free tier atau free model dengan batas tertentu, sedangkan model/layanan lain dapat berbayar. Selalu periksa label harga dan ketentuan provider sebelum mengirim request.

Bisakah memakai API key berbayar sendiri?

Bisa melalui provider yang didukung atau Custom Provider jika endpoint menyediakan OpenAI-compatible Chat Completions API.

Apakah chat disimpan?

Sesi dan data runtime disimpan secara lokal sesuai konfigurasi aplikasi. Saat memakai model cloud, pesan yang dikirim tetap diteruskan ke provider untuk diproses.

Bisakah memakai YookAI tanpa internet?

Chat cloud memerlukan jaringan. Penggunaan offline dimungkinkan hanya bila model lokal seperti Ollama sudah berjalan dan dapat dijangkau dari perangkat YookAI.

Apakah semua provider mendukung reasoning, vision, atau tools?

Tidak. Kapabilitas bergantung pada model, adapter, endpoint, dan akses akun. Jangan menganggap fitur dari satu provider otomatis tersedia di provider lain.

Di mana data YookAI tersimpan?

Runtime default berada di ~/.yookai/, termasuk konfigurasi, sesi, memory, cache, dan lampiran.

18. Checklist penggunaan pertama

Pastikan semua tahap dasar berjalan sebelum mulai menggunakan YookAI secara rutin.

  • Source sudah diekstrak dan folder root benar.
  • Python dan dependency berhasil dipasang.
  • Server berhasil berjalan tanpa error startup.
  • Web UI dapat dibuka di browser melalui localhost.
  • Provider dan model yang valid sudah dipilih.
  • API key dimasukkan dengan aman bila diperlukan.
  • Pesan percobaan berhasil memperoleh respons.
  • Sesi percakapan tersimpan dan dapat dibuka kembali.
  • Sudah memahami batas kuota, biaya, dan privasi provider.
  • Data penting sudah memiliki backup.
